# Tedrix

Every machine you look after, in one window. Remote Desktop, live screens, SSH and PowerShell, files, tunnels, Telnet and serial consoles, for Mac and Windows.

Download the newest version from the Releases section on the right, or at https://tedrix.app

- Mac with Apple silicon (M1 or newer): Tedrix-arm64.dmg
- Intel Mac: Tedrix-x64.dmg
- Windows, with Start menu shortcut: Tedrix-Setup.exe
- Windows, no install: Tedrix.exe
